## 📂 Repository Structure & Projects

This portfolio is divided into specialized modules. Click on each directory to view specific code and documentation:

### 1. 🔍 Network Reconnaissance & Audit
* **Core Tools:** Bash Shell scripting, Native Compilers, [Nmap](https://nmap.org) (v7.991+)
* **Files:** 
  * `mi_primer_script.sh`: A lightweight Bash automation script designed to streamline the information gathering phase.
  * `reporte_seguridad.txt`: Real live traffic and port audit report generated from automated target evaluation.

### 2. 🔬 [Malware-Sandbox](./Malware-Sandbox/) (Click to view project)
* **Core Tools:** Python 3, [Watchdog Library](https://pypi.org) (v6.0.0+)
* **Description:** A live automated Endpoint Detection and Response (EDR) core prototype that logs file-system anomalies and flags indicators of compromise (IoCs) such as droppers and anti-forensics evasion.
